Free and open source, for macOS 14 or newer on Apple silicon

Name a control on your Mac and Thataway points at it.

Press Option Space, say or type the control you want, and a pointer arcs from your mouse to it. Your own cursor stays where it is, nothing gets clicked, and what is on your screen stays on your Mac.

It points. You do the clicking.

The tree first, vision second.

Controls come from the accessibility tree with their real bounds. The shortlist re-ranks on every keystroke (0.067 ms p50 on a Chrome window), and the local model starts only on a miss.

  • 12 of 12 targets found on a Google Chrome window
  • 0.067 ms p50 and 0.081 ms p90 to rank them
  • Vision fallback: H Company's Holo1.5-7B (Apache 2.0), run on your Mac

It says when it is guessing.

An exact answer gets a solid ring, a guess gets a dashed amber ring and a question mark, and no match gets no pointer.

  • Exact, from the tree
  • A guess, ending in ?
  • No match, no pointer

Excluded means never read.

Password managers, banks, Messages, Mail and Notes are checked by bundle ID before the first accessibility call, and the list is a text file you can edit.

See what is excluded by default

Lessons wait for you.

A lesson dims everything but the next control and moves on when the tree shows you did it.

  • Two built in: open this app's settings, and find something in this app
  • Next Step and Previous Step when you want to move on your own
  • Each step waits up to 120 s before it says it has stalled

Show it once with Watch me.

Record a few clicks and Thataway saves them as a lesson of control names that anyone can replay.

  • Teach Me, Record a Workflow, click through, then Stop Recording & Save
  • Saved as control names in ~/.config/thataway/lessons, with no screen coordinates

Build it, allow it, then ask for a control.

  1. Build the app

    You need Xcode for the Swift toolchain. The build script makes a menu bar app with no Dock icon.

    git clone https://github.com/jke48222/thataway.git
cd thataway
bash Tools/make-app.sh
open build/Thataway.app

  2. Allow Accessibility

    Open System Settings, then Privacy & Security, then Accessibility, and turn on Thataway. It does nothing without this permission.

  3. Press ⌥ Space and name it

    Tap to type, or hold to say it out loud. Type settings and press Return, and the pointer arcs from your mouse to the control. Escape closes the bar.

If your keychain has a Developer ID certificate, make-app.sh signs with it and the hardened runtime, or else with an Apple Development certificate. Without either it signs ad hoc, and macOS asks for Accessibility again after every rebuild. No build is notarized yet.

What it reads, and where that goes.

What it reads
The frontmost app's accessibility tree, which includes on-screen text such as labels, values and window titles. Only when the tree has no answer and the vision fallback is installed, it also takes an image of that app's windows.
When
When you switch apps. On accessibility events, at most one walk per second (every 250 ms while a lesson is watching). And on a 3‑second heartbeat that pauses after 60 seconds without keyboard or mouse input.
Where it goes
The tree stays in memory and is never sent anywhere. The image goes to the local model process over a pipe, or through a temp file only you can read, deleted after the reply. The app has no network code.
What it saves
Only what you make, under ~/.config/thataway/: your exclusion list and any Watch me recordings. A recording stores control names, and those can contain personal text.

Never read, by default

26 bundle-ID prefixes are checked before the first accessibility call, and 16 window-title patterns are checked too. Excluded windows are never read and never captured. The rules live in ~/.config/thataway/exclusions.conf, which reloads when you save it.

Questions

Does Thataway move my cursor or click anything?

No. The pointer is drawn on a click-through layer above your apps. Your own mouse pointer stays where it is, and Thataway never clicks. You do the clicking.

Which apps does it work in?

It reads the frontmost app's accessibility tree, so it does best where controls appear in that tree with labels, including menus and the menu bar. The one measured result so far is a Google Chrome window: 12 of 12 targets. There is no evaluation on a second app yet. Canvases and custom-drawn controls need the optional vision fallback, and excluded apps get a refusal instead of a pointer.

Does anything leave my Mac?

Screen content does not. The accessibility tree stays in memory, and a vision image goes only to the local model process. The app has no network code today. The planned signed build will contact Polar when you activate or free a Mac, and will check for updates only if you opt in.

Do I need the vision model?

No. Without it, answers come from the accessibility tree alone. With it, H Company's Holo1.5-7B runs on your Mac only when the tree has no answer, and the tree still aims a crop of the window so the model reads fewer pixels. Its fastest usable single call took 1,657 ms on an M5 Pro.

How fast is it?

Ranking the controls of a Chrome window took 0.067 ms at p50, which is why the shortlist can update on every keystroke. The time from keypress to pointer has not been measured as one run yet, and neither have idle CPU and memory.

Does voice need the internet?

No. Hold Option Space to speak. Recognition has to run on your Mac, in US English. If your Mac cannot recognize speech on device, voice turns off rather than using a server.

Can I change what is excluded?

Yes. Edit ~/.config/thataway/exclusions.conf and save. Thataway reloads it, and if the file cannot be read it fails closed.

What is not done yet?
  • No signed download. Today you build it with Xcode.
  • Accuracy is measured on one Chrome window only.
  • Watch me has not been tested with a person's own clicks yet.
  • Microphone and speech permissions use the system's first-use dialogs.
  • The vision fallback needs a 5.65 GB model and a Python setup you do yourself.
